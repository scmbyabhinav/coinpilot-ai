# COINPILOT AI v0.9 — Manual Trading Workflow

## Built for the selected workflow
- Windows-first, personal-use trading terminal.
- Execution mode selector: Virtual Trading / Manual Real Trading.
- Virtual mode retains simulated BUY execution.
- Manual Real mode displays signals and Binance market links only; the user reviews and places orders independently.
- Trade Desk now displays BUY, SELL and WAIT across the configured watchlist.
- SELL is framed as a Spot exit/review warning, not a short-selling instruction.
- BUY cards include ATR-based illustrative levels, rationale and risk sizing reference.
- Open virtual positions display stop/target attention warnings.

## Not included
- No Binance account connection.
- No real order placement, API key storage or automatic execution.
- No claim that signals are profitable or validated.

## Validation
- Python source syntax compiled successfully during packaging.
- Live Binance connectivity and full interactive runtime were not tested in this build environment.
